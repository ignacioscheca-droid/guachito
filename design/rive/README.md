# Guachito Rive master

Built through the Rive editor's MCP server (Rive desktop app, file "Gauchito v1")
from the artist's full-body poses. The artist's modular rig parts don't rebuild
the character yet (see `guachito_assets/PENDING_FOR_PRODUCTION.md`), so this is a
pose-swap rig with vector eyelids, not a bone rig.

Parts: `parts/` (generated by `design/tools/rive_parts.py`): the web poses
`g_idle`, `g_jump`, `g_celebrate`, `g_thumbs` (906 × 990 box, boots at y = 982.5)
and `g_idle_moustache`, a moustache overlay drawn above the eyelids.

## Artboard `Guachito` (906 × 1210, transparent)

The pose box sits at the bottom; the 220 px above it is room for the jump.

```
Root (453, 1202.5) = the boots
├─ Shadow            radial ellipse, shrinks during the jump
├─ Idle              breathes (scale about the feet)
│  ├─ idle_img
│  ├─ Lid_A, Lid_B   skin ellipse + lash stroke, scaleY 0 = open, 100 = closed
│  └─ moustache_img  over the lids
├─ Jump / Celebrate / Land   one pose each, shown by opacity
└─ Confetti          14 shapes, scaled 210%
```

## Animations (60 fps)

| name | length | what |
|---|---|---|
| `idle` | 2.4 s loop | breathing + one blink |
| `habit_completed` | 1.6 s | squash → jump → celebrate + confetti → thumbs up |
| `celebrate` | 1.2 s | two bounces + confetti |
| `return_to_idle` | 0.3 s | thumbs → idle settle |

Every animation keys all pose visibilities on frame 0, so any can follow any.

## State machine `Guachito` and why the app doesn't use it

The file has a state machine (`idle` → `habit_completed` / `celebrate` →
`return_to_idle` → `idle`) driven by view-model triggers `habit_completed` and
`celebrate`. **Exports from the free Rive plan drop the view model** (and add
watermark artboards), so the app plays the linear animations by name instead
(`app/src/components/RiveGuachito.tsx`). On a paid plan, switch the component back
to the state machine + `useViewModelInstanceTrigger`.

## Updating

1. Edit in Rive (or rerun the MCP build).
2. `python3 design/tools/rive_export.py` writes `app/public/rive/guachito.riv`.
